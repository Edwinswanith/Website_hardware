## What this is

A one-page site for **Tech Cogniverse**, built around one generated film: a robotic arm places a chip on a board, light runs out along the traces, the camera pulls back to the lab. The robotics imagery is a metaphor for precise systems work; Tech Cogniverse does not sell robotics, and no copy may imply it does. Facts come only from `src/content/` (copied from the company's published site); never add a claim, metric, client or price that isn't there.

## Architecture

- `src/film/Film.tsx`: the whole film section. One sticky stage with a `<canvas>`; scroll progress `f` (0..1 through the section) picks what is drawn. Timeline: A `0–0.40` Veo clip `v1` (frames), B `0.40–0.62` dive into the chip to still `s3`, C `0.62–0.80` hold on the traces, D `0.80–1` pull back to still `s4`. B and D are drawn from stills until their clips exist. Chapter text lives in `BANDS` (fade-in / plateau / fade-out ranges in `f`); each band gets `--k` (0..1) and sits in the calmest part of its frames with a local scrim.
- Rendering: one rAF loop that lerps toward `scrollY` and rests when settled. Frames are fetched as compressed blobs and decoded off the main thread with `createImageBitmap` in a ±10-frame window around the playhead (released beyond ±14); drawing uses the nearest decoded frame. Inside the clip, only a new frame index triggers a redraw.
- Phones (< 900px) never download frames: they get the four stills as 3:4 crops. Reduced motion and no JS (`html:not([data-js])`, set by the inline script in `layout.tsx`) turn the film into five stacked stills, each carrying its chapter.
- `src/film/manifest.ts` is generated by `npm run frames`; it lists the approved clips. Add a clip to `CLIPS` in `tools/media/frames.mjs` only after it has passed review.
- `src/app/page.tsx` composes `<Film />` (the scroll section), then work, making-of (`FilmStrip`), trust and contact sections from `src/content/`. `next.config.ts` sets `output: "standalone"` and `images.unoptimized` because frames and stills are pre-built, not run through `next/image`.
- `src/film/FilmStrip.tsx`: "How this film was made", pointer and slider scrubbing through the clip frames.

## Media and generation

- Masters live in `assets-src/film/` and are gitignored (`s1..s4.jpg` stills, `v*.mp4` clips); their prompts are committed next to them.
- `public/film/` (frames, stills) is generated by `npm run frames` and served as-is. `sharp` is a devDependency used only by that script.
- `tools/gen/veo.py` (`python3 veo.py <out.mp4> <prompt-file> <first.jpg> <last.jpg> [model]`) submits one Veo first+last-frame job and downloads it. It reads no API key; the environment's proxy injects credentials. Never add a key to any file.
- Every paid generation needs the owner's explicit approval first (purpose, model, settings, price). Chain the next clip from the previous clip's real last frame, not from the still, so the join is invisible.
- Generated images and clips never contain text, logos or interface.

## Design

Tokens in `src/app/globals.css`, taken from the film: lab white `#f4f2ee`, ink `#1a1c1e`, board green `#0f3b2e`, copper `#c07a3e` (graphics) / `#8a5024` (text). Type: Geist and Geist Mono. Human gates are drawn dashed. No em dashes in copy.
